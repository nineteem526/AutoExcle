# 安装及使用指南

> 本页仅适用于仓库早期源码，不是 V13 安装指南。V13 为专用 `.xlsm` 工作簿，完整流程见[项目流程说明](PROJECT_REPORT.md)；不能通过导入本页两个源码文件获得全部 V13 功能。本页列号和布局示例仅适用于早期版本。

## 适用布局

| 位置 | 要求 |
|---|---|
| 总览表名称 | `Summary overview list` |
| 明细表名称 | `Shipping planning`，或修改模块顶部 `DETAIL` 常量为实际名称 |
| 明细表第 2 行 | 包含唯一的 `Main Components`、`Area`、`Planned Shipping order` 表头 |
| 明细记录 | 从第 3 行起扫描；项目名称为空的行不参与展示 |
| 总览第 2 行 | 从 B 列起连续填写唯一的正整数批次 |
| 总览区域 | 从第 7 行起，A 列每个项目行重复区域名；同一区域必须连续 |
| 项目展示区 | B 列至最后一个批次列；不允许手工非空内容、合并单元格或跨多个单元格的数组公式 |

同一区域的连续行构成一个区域块，区域间可留空行。新增区域必须先配置其区域块。新增批次必须先在总览第 2 行增加编号，并自行维护日期、状态等表头信息。

## 安装

1. 备份原工作簿，另存为 `.xlsm`。
2. 按 `Alt + F11`，在工程窗口中选中目标工作簿。
3. 选择“文件 → 导入文件”，导入 `src/ShippingTools.bas`。
4. 将 `src/SummarySheetEvent.txt` 中的代码放入总览表对应的工作表模块，不是普通模块或 `ThisWorkbook`。
5. 如果已有同名过程或双击事件，先备份并合并或替换对应旧逻辑，不能重复定义，也不能删除无关业务宏。
6. 核对模块顶部的工作表名称。源码已脱敏，实际明细表名称可能需要调整。
7. 保存并返回 Excel，按 `Alt + F8`，运行 `RefreshShippingSummary`。
8. 可通过“插入 → 形状”添加按钮，右键“指定宏”，选择本工作簿的 `RefreshShippingSummary`。

只对来源可信的文件按组织政策启用宏。不要关闭宏安全保护或启用所有宏。组织策略阻止运行时应联系 IT。

## 日常操作

- 双击总览的非空项目单元格，输入已有目标批次并确认。
- 该操作可能用固定数字替换 Planned 列的引用公式，这是人工计划覆盖自动建议的预期行为。
- 直接新增明细或批量调整后，运行刷新宏，更新展示容量和数据范围。
- 核对结果后保存。不要直接剪切或拖动总览公式。
- 恢复自动建议需在 Planned 单元格恢复对应 Automatic 引用，例如同一行 `=N18`，实际列号以工作簿为准。

## 错误处理

刷新前会检查未配置区域、未配置批次、无效序号、展示区手写内容及不支持的公式结构。出现错误时应先修复提示原因，不能忽略提示继续使用可能不完整的总览。

自动修改流程发生失败时会尝试恢复原 Planned 值或公式，但已发生的总览插行不会自动回滚。修复原因后再次刷新；必要时使用备份恢复。

## 交付与协作

可以将源码安装到同事已有的同结构工作簿，无需传递原业务数据。各工作簿副本之间不会自动同步；建议指定主文件和维护责任人，避免同时编辑覆盖。
